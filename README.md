# Hi, I'm Yifan Ouyang

I build AI applications and model deployment tools.

## Featured project: Lumen Vision 460M

[![XERJ Corpus Hub contributor](https://hub.xerj.org/contributors/yifan-2004/badge.svg)](https://hub.xerj.org/contributors/yifan-2004)

A compact single-image vision-language model deployment project. My engineering work includes:

- Local/offline folder inference with JSONL and standalone HTML reports.
- Processor keyword-handling fixes and image-token/visual-embedding validation.
- Regression tests and documented CPU smoke-test results.

**Selected contribution:** the deployment tooling and validation work was selected for the [XERJ Corpus Hub](https://hub.xerj.org/contributors/yifan-2004), with attribution and a pinned source revision.

[Repository](https://github.com/yifan-2004/Lumen-Vision-460M) · [Weights and model card](https://huggingface.co/yifanouyang/Lumen-Vision-460M) · [XERJ corpus](https://hub.xerj.org/corpus/yifan-2004--lumen-vision-460m)

The model and core implementation come from [Tether AI Research / VisionPsy Nano](https://github.com/tether-ai-research/qvac-visionpsy-nano). My contribution focuses on the deployment workflow and reliability; the released base weights are unchanged.
